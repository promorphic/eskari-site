The who-goes-first problem

Someone always has to go first. When one company's agent buys from another's, one side pays and hopes, or delivers and hopes. Agents can negotiate in seconds. They still can't trust each other.

Lock both legs.
Settle once.

Both agents commit to the same terms and each leg is locked in escrow. When the conditions hold, both legs settle in a single atomic transaction. When they don't, both unwind.

Step through it below, then switch to the path where a condition fails.

One call opens
an escrow

Give your agent a way to trade with counterparties it has never met. Open, lock, wait for the result. Eskari reports one outcome for both legs.

agents/procure/settle.ts TypeScript 
import Eskari from "@eskari/sdk";

const eskari = new Eskari({
  apiKey: process.env.ESKARI_KEY,
});

// Both agents sign the same terms.
const escrow = await eskari.open({
  buyer: "procure-01@acme",
  seller: "broker-07@northfield",
  payment: {
    asset: "USDC",
    amount: "25000.00",
  },
  delivery: {
    asset: "GPU-HOUR",
    amount: "2000",
  },
  settleWhen: "capacity.attested",
  unwindAfter: "15m",
});

// Lock this agent's leg.
await escrow.lock();

// One outcome for both legs.
const result = await escrow.done();
// "settled" | "unwound"

Questions

What does “atomic” mean here?

The payment and the asset move in the same transaction. Either both legs complete or neither does. There is no moment where one side has paid and the other has not delivered.

What happens if a condition is not met?

Both legs unwind. The payment returns to the buyer and the asset returns to the seller, in one transaction. Every escrow carries a deadline, so nothing stays locked indefinitely.

Who can see a deal?

The buyer, the seller, and anyone they both add as an observer, such as an auditor. Canton shares a contract only with its stakeholders. Other participants on the network never receive it.

What does Eskari itself see?

What the escrow needs to hold and release the two legs: the parties, the legs, the conditions and the deadline. Eskari is a party to the escrow contract. It is not a party to the rest of your agents' business.

How do agents integrate?

Through an API and SDK. An agent opens an escrow, locks its leg and waits for a single result. You set limits on which agents can open escrows, with whom, and for how much.

What can be settled?

We are starting with stablecoin payments against tokenized assets, data licences, compute credits and invoices. If your agents trade something else, tell us when you request access.

Is Eskari live?

Not yet. Eskari is pre-launch. The screens and figures on this page are illustrative. Request access and we will reach out as we open up.
